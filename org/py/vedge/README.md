Video game engine made from boredom :)

Directory meanings:
* `data` Data structures, like JSON and binary
* `graphics` Anything graphics
* `i` 1D things (couldn't use 1 in package name)
* `ii` 2D things (same reason for i)
* `infa` Vital infrastructural classes that support the engine
* `infa.java` Raw stuff, like handling errors and reading files
* `input` Input stuff
* `util` Utilities like the holy Sparry class
